# PyDESeq2 Usage Guide

Use this skill for Python-first bulk RNA-seq differential expression with DESeq2-style modeling.

Example prompts:

- "Run PyDESeq2 on this count matrix comparing treated vs control while adjusting for batch."
- "Check whether this matrix is raw counts before differential expression."
- "Create a DE results table and volcano plot from PyDESeq2 output."

The agent will validate raw counts, align metadata, fit the model, define contrasts explicitly, and export reproducible result tables.
